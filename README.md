# Mood-Based Music Recommender System

## Overview
The Mood-Based Music Recommender System is a Python-based web application developed using Streamlit that recommends songs based on the user's selected mood. The application provides an interactive and user-friendly interface for discovering music 
that matches different emotional states and listening preferences.

## Tools & Technologies Used
- Python
- Streamlit
- Visual Studio Code (VS Code)

## Features
- Interactive Streamlit interface
- Mood-based song recommendations
- Personalized music suggestions
- Easy navigation and song selection
- Fast and responsive user experience

## Project Workflow
1. User selects a mood from the available categories.
2. The application processes the selected mood.
3. Songs matching the mood are retrieved.
4. Recommended songs are displayed to the user.

## Supported Mood Categories
- Happy
- Sad
- Feeling Low
- BGM
- Motivated
- Romantic
- Party
- Mass Beat
- Pleasant
